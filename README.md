# Firebase Studio

This is a NextJS starter in Firebase Studio.

## Getting Started

To get started, take a look at src/app/page.tsx.

## Setting up your API Key

To use the AI features in this application, you need to provide a Gemini API key.

1.  Create a file named `.env.local` in the root of the project.
2.  Add the following line to the file:

    ```
    GEMINI_API_KEY="YOUR_API_KEY_HERE"
    ```

3.  Replace `"YOUR_API_KEY_HERE"` with your actual Gemini API key.
4.  The application will automatically use this key to power the AI features.

**Important:** Keep your API key private and do not commit it to version control.
